# E-commerce Sales Analysis Project

## Overview
This project analyzes e-commerce sales data to uncover trends, customer behavior patterns, and sales performance metrics. It combines data analysis with machine learning to provide insights and sales predictions. Built using Python's data science stack (Pandas, Matplotlib, Seaborn) and TensorFlow for predictive modeling.

## Features
- Historical sales trend analysis
- Customer segmentation and demographics analysis
- Product performance evaluation
- Sales forecasting using TensorFlow neural networks
- Interactive visualizations and heatmaps
- Geographical sales distribution mapping
